### 📖 Descripción 
Este proyecto implementa un dashboard interactivo para la visualización de emergencias históricas en el departamento de Antioquia, Colombia. Es una migración de un tablero de Power BI a una solución open-source basada en Python con Dash y Plotly.

El sistema permite explorar la relación entre eventos climáticos (ENSO) y emergencias asociadas a lluvias, movimientos en masa, inundaciones, entre otros fenómenos naturales.

### ✨ Características
📊 Páginas del Dashboard
Página	Descripción
Todas las Emergencias	Visión general de todas las emergencias registradas
Emergencias por Lluvia	Filtro específico para eventos asociados a lluvias
Amenazas Secundarias	Exploración por grupos de amenazas (Sismos, Movimientos en Masa, Inundaciones, etc.)

### 🗺️ Visualizaciones
Mapa interactivo de Antioquia con puntos por municipio coloreados por Subregión

Gráfico de líneas con emergencias por mes del año (con etiquetas permanentes)

Gráficos de barras para Top municipios, Subregiones y Tipos de Amenaza

Tabla dinámica con total de emergencias por año

Métricas en tiempo real (Total Emergencias, Municipio Más Afectado)

Slider interactivo para filtrar por rango de años

### 🔍 Filtros Interactivos
Rango de años (1903 - actualidad)

Selección por clic en gráficos de barras (filtra todos los demás visuals)

Dropdown para seleccionar grupos de amenazas secundarias

### ⚙️ Requisitos
